# 行测刷题工具 v0.1

## 启动方式

```bash
cd 刷题工具
python3 main.py
```

无需安装任何第三方依赖，纯 Python + tkinter。

## 功能概览

### 已实现
- **题库管理**：新建/选择已有题库（根目录 = "根"）
- **录入模式**：
  - 题干：Markdown 文字 / 截图
  - 选项：4格文字 / 单张大截图 / 4张小截图（默认ABCD，可扩展到H）
  - 答案：文字 / 截图
  - 正确答案标记
- **分支/Tag 系统**：
  - 树形分支选择（对应文件夹结构）
  - 递归创建子分支/子Tag
  - Tag 多选（可叠加）
  - 重命名分支/Tag
- **数据持久化**：题目以 `Q0001/` 格式保存到分支目录
  - 题干 → question.md 或 question.png
  - 选项 → options/A.md 或 options/A.png
  - 答案 → answer.md 或 answer.png
  - 元数据 → meta.json（含 tags、正确选项索引等）

### 待实现（刷题模式）
- 按分支/Tag 筛选
- 限时刷题
- 错题本
- 随机/顺序模式
